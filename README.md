## About

An **event management website** that allows users to browse events, register for events, and manage event listings. Features a clean professional design suitable for event organizers and attendees.

Built with **vanilla HTML, CSS, and JavaScript** -- organized folder structure with separate CSS and JS directories.

---

## Features

| Feature | Description |
|---------|-------------|
| Event Listings | Browse upcoming events |
| Event Details | View full event information |
| Registration | Register for events |
| Search Events | Find events by keyword |
| Clean UI | Professional event design |
| Responsive | Works on all devices |
| Organized Code | Separate CSS and JS folders |
| Fast Loading | Optimized performance |
